Quiet Room

A Quiet Room is an individual personal project created to bring together, within a single project, several models made using Blender. Some textures were found online, while others were created from photographs I took. I then edited these photographs in Photoshop to give them the desired aesthetic.

This project was completed over a period of two weeks in my spare time. I learned how to use new Blender tools to apply textures, as well as how to work with basic lighting.
